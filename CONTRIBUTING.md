# Contribution à FASTEK-CENTRAL

## Branches
- `main` : production (protégée)
- `develop` : intégration
- `staging` : validation
- `feature/xxx` : nouvelles fonctionnalités
- `fix/xxx` : corrections

## Commits
Utiliser Conventional Commits :
- `feat:` nouvelle fonctionnalité
- `fix:` correction
- `docs:` documentation
- `chore:` maintenance
- `test:` tests
- `refactor:` refactoring

## Secrets
Aucun secret ne doit être commité.
Utiliser GitHub Secrets et Supabase Secrets.

## Pull Requests
- Une PR = une intention claire
- Description obligatoire
- Tests et lint doivent passer
